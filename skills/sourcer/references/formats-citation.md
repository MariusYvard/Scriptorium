# Formats de citation

Trois normes courantes. Choisir selon le genre et la consigne. Nettoyer chaque URL des paramètres de suivi. Vérifier que chaque lien et chaque DOI résout.

## APA 7

Citation dans le texte : (Auteur, année) ou Auteur (année).

Références, ordre alphabétique :

```
Auteur, A. A. (année). Titre de l'ouvrage. Éditeur.
Auteur, B. B. (année). Titre de l'article. Nom de la revue, volume(numéro), pages. https://doi.org/xxxx
```

Usage : sciences humaines et sociales, gestion, psychologie.

## Vancouver

Citation dans le texte : numéro entre crochets [1], dans l'ordre d'apparition.

Références, ordre d'apparition :

```
1. Auteur AA, Auteur BB. Titre de l'article. Abrév Revue. Année;volume(numéro):pages.
2. Auteur CC. Titre de l'ouvrage. Ville : Éditeur ; année.
```

Usage : médecine, sciences de la vie, ingénierie.

## Notes ou références numérotées (hors académique)

Pour un article ou un rapport professionnel, références numérotées en fin de document.

```
[1] Organisation. (année). Titre du rapport. URL nettoyée.
```

## Nettoyage des URL

Retirer tout paramètre de suivi après le point d'interrogation : utm_source, utm_medium, utm_campaign, fbclid, gclid et équivalents. Conserver les paramètres nécessaires à l'accès à la ressource. Préférer l'URL canonique ou le DOI.

## Règles

- URL et DOI vérifiés, ils doivent résoudre vers la ressource citée.
- Date d'accès indiquée pour une ressource web susceptible de changer.
- Une seule norme par document, appliquée de bout en bout.
- Jamais de référence inventée ni de DOI fabriqué.
