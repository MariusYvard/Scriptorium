# Lexique banni et substitutions

Termes et tournures à éviter, avec une substitution sobre. La règle générale : remplacer l'emphase par le fait, et la périphrase par le verbe simple.

## Adjectifs d'éloge

| Banni | Substitution |
| --- | --- |
| pivotal, crucial | déterminant, ou nommer l'effet précis |
| emblématique | représentatif, ou citer le fait |
| incontournable | nécessaire, ou supprimer |
| visionnaire, révolutionnaire | nouveau, ou décrire ce qui change |
| riche tapisserie | ensemble, diversité, ou détailler |

## Verbes et tournures faibles

| Banni | Substitution |
| --- | --- |
| témoigne de | montre, indique, ou donner la preuve |
| souligne, met en lumière | montre, ou citer le fait |
| reflète | correspond à, résulte de |
| se présente comme | est |
| façonner le paysage | modifier, structurer, ou nommer l'effet |
| au-delà de | en plus de, ou supprimer |
| changer, évoluer (flous) | croître, diminuer, se stabiliser |

## Métadiscours à supprimer

- "Voici le texte", "dans cet article", "nous allons voir", "en tant qu'IA".
- "Il est important de noter que", "force est de constater".
- Les conclusions sur l'héritage, l'impact durable ou le futur quand elles n'ajoutent pas de fait.

## Vague à chiffrer

| Vague | Substitution |
| --- | --- |
| plusieurs, nombreux | le nombre exact |
| récemment | la date |
| une forte hausse | le pourcentage |
| la plupart | la proportion (7 sur 10) |

## Principe

Une tournure d'emphase signale souvent une absence de fait. Quand le terme banni vient sous la plume, chercher le fait précis qu'il essaie de remplacer, et écrire ce fait.
